# GlimWorld
This is a GitHub Repository Source code, info about GlimWorld!

## About
GlimWorld is a creative community and social game-creation platform where anyone can play games, build interactive creations, learn through educational content, and explore a constantly growing world of community made experiences. Its characters are also Glims and GlimWorld is built to be a space where creativity, community, and exploration come together in an environment!
